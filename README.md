# IcueLite

Alternative légère à Corsair iCUE pour Windows : éclairage, DPI, macros, ventilateurs iCUE LINK, suivi de l'alimentation AXi… sans le logiciel Corsair.

Appareils visés : clavier Vanguard Pro 96 Hall Effect, clavier K100 RGB OPX, souris Ironclaw RGB, casque Virtuoso RGB Wireless XT, boîtier iCUE LINK 5000T LX RGB (hub, ventilateurs LX120, bandes Aurora) et alimentation AX1600i. Le watercooling Nautilus RS ARGB et la mémoire Vengeance DDR5 passent par la carte mère : IcueLite les affiche mais ne peut pas les piloter directement.

Projet indépendant, sans lien avec Corsair.

**Télécharger :** prends `IcueLite.exe` dans la dernière [version publiée](../../releases/latest). L'appli se met ensuite à jour toute seule.

Mode d'emploi : [GUIDE.md](GUIDE.md).
